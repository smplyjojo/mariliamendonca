# Marília para sempre

Página responsiva de fã para celebrar a trajetória e a música de Marília Mendonça. Feita com HTML, CSS e JavaScript puro.

## Como executar

Abra `index.html` em um navegador. Não é necessário instalar dependências ou iniciar um servidor.

## O que tem na página

- Biografia resumida e momentos marcantes da carreira.
- Player incorporado do Spotify e links para músicas no YouTube.
- Galeria com fotos hospedadas no Wikimedia Commons e links para as páginas de origem.
- Mural de fãs para compartilhar mensagens, curiosidades e músicas favoritas. Os recados são guardados somente no `localStorage` do navegador atual.
- Layout adaptado para dispositivos móveis.

O player do Spotify e as imagens precisam de conexão com a internet. Este é um projeto de fã, sem vínculo oficial com a artista ou sua equipe.
